An analysis of party support, issue priorities, demographic cleavages, voter personas and population-scale estimates across January–December 2025. Drawing on 49 weekly YouGov polling waves covering approximately 1,700 adults each. The analysis integrates party vote share tracking, issue salience data across 13 demographic subgroups, statistical correlation analysis, voter persona construction, and population-scale estimates using ONS age data and Ipsos 2024 turnout rates.
